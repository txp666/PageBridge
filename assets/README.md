# PageBridge icon

`PageBridge-icon.png` is the original transparent PNG generated for this project with the built-in imagegen tool on 2026-10-24. It combines an open book and a bridge arch on a blue macOS tile. No external logo is used.

`PageBridge.icns` is generated locally by `python3 scripts/build-icons.py` using macOS `sips` and `iconutil`. The build copies both representations into the application bundle. Keep the original PNG when changing export sizes.

## Generation prompt

Use case: logo-brand. Create a finished macOS application icon for PageBridge, a native PDF translation and side-by-side reading app. One single centered icon, square 1024x1024 composition, generous transparent outside margin around a blue rounded-square macOS icon tile. The symbol is a crisp white open book whose two facing pages elegantly form a bridge arch in the central negative space, conveying reading and connection between languages. Match a calm professional blue palette already used by the app; a subtle azure-to-deep-blue gradient and restrained soft dimensional lighting, no glossy clutter. Bold simple silhouette recognizable at 32 pixels, clean geometric curves, balanced symmetry with a small purposeful page-fold detail. No words, no letters, no tiny lines, no flags, no translation badges, no border, no extra objects, no watermark. Make the space outside the rounded-square tile genuinely transparent. This is the final production icon asset, not a mockup sheet.
