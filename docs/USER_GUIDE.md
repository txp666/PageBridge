# 使用 PageBridge

本指南对应 **0.3.0 / build 12**，包含 OpenAlex 文献搜索、Sci-Hub／公开 PDF 全文来源、应用内站点验证，以及文档整理、翻译、对照阅读、批注和文档助手。适用于手册、报告、教材、合同和论文等带文本层的 PDF。

从 [v0.3.0 发布页](https://github.com/txp666/PageBridge/releases/tag/v0.3.0)下载 `PageBridge-0.3.0-macOS-arm64.zip`；同页提供项目源码、第三方源码和 SHA-256 校验文件。包体大小以发布页为准，实际验收范围见[验证记录](VERIFICATION.md)。

## 安装或更新

当前安装包面向 Apple Silicon Mac（M 系列），部署目标为 macOS 14 或更高版本；Intel Mac 不适用此包，macOS 14 尚未完成实机验证。

1. 退出正在运行的 PageBridge。
2. 解压 `PageBridge-0.3.0-macOS-arm64.zip`，把 `PageBridge.app` 放到“应用程序”，更新时替换旧的应用文件。
3. 打开应用，在 PageBridge 菜单的“About PageBridge”中确认版本为 `0.3.0 (12)`。

文档、批注和服务配置位于独立的用户数据目录，替换应用文件会继续使用已有数据；API Key 继续保存在钥匙串。无需重新导入文档或重新翻译。该发行包采用 ad-hoc 签名，尚未完成 Developer ID 签名与 Apple 公证。更新包的 Ed25519 签名不替代 Apple 签名或公证。

## 检查与安装更新

在 macOS 菜单栏打开 **PageBridge → 检查更新…**，可手动查看新版本。**自动检查更新**用于决定是否定期检查；首次提示会征求你的同意，可随时从同一菜单关闭。

发现更新后，Sparkle 窗口显示版本与更新说明，由你选择下载、安装或跳过。应用不静默下载或安装更新；更新来自本项目 GitHub Releases，通过 HTTPS 获取，并校验 appcast 与更新包签名。

翻译进行时，“检查更新…”暂不可用，自动检查也会暂缓。如果已经同意安装更新而随后开始翻译，安装和重新启动会等翻译结束。更新不会主动取消当前翻译。

更新检查不发送 PDF、笔记、翻译密钥或系统配置画像。若网络不可用或签名检查失败，保留当前应用；可稍后重试，或从发布页手动下载安装。早期没有更新菜单的本地包需先手动安装此版。已是当前版本时不会重新安装同一 build。

## 开始阅读

打开 `PageBridge.app`，拖入 PDF 或点击左上角 `+`。左侧文档库保留导入记录。也可以点击侧栏“示例 PDF”，选择五份公开论文之一；应用会建立独立副本，不修改内置示例。

示例从 4 页短文到 19 页公式论文，原始作者和许可见示例窗口的“原文与许可”。打开示例不会自动翻译。

## 搜索在线文献

点击侧栏本机文档搜索框下方的“搜索在线文献”，或从左上角 `+` 菜单进入。OpenAlex 负责检索，Sci-Hub 和公开 PDF 是可选的全文来源；无需配置翻译服务或 API Key，也不调用语言模型。

1. 输入标题、关键词、DOI（例如 `10.1371/journal.pcbi.1003833`）或完整 `https://doi.org/…` 链接，再点击“搜索”或按 Return。输入过程中不发送请求。已有 DOI 时，选择 Sci-Hub 来源，在空结果区域点击“直接打开此 DOI 的全文”即可，无需先发起或等待 OpenAlex 检索；支持原始 DOI、`doi:` 前缀和 doi.org 链接。
2. 结果展示标题、作者、年份、来源与 DOI，每页最多 20 条。可点击“加载更多”；勾选“仅开放获取”后重新点击“搜索”。修改搜索词或筛选条件会清空上次结果。
3. 在“全文来源”中选择 **Sci-Hub**（默认）或 **公开 PDF**，再点击结果中的“打开全文”。Sci-Hub 使用该结果的 DOI 查找全文；公开 PDF 使用 OpenAlex 返回的开放获取下载地址。没有 DOI 的记录可尝试公开 PDF 来源。搜索结果不代表所选来源一定收录全文，“仅开放获取”只筛选 OpenAlex 的记录。
4. 应用下载并校验文件，通过后导入本机文档库并直接打开；随后可像本地文件一样翻译、批注、提问和导出，不会自动开始翻译。在文件夹中导入的新文件归入当前文件夹。
5. 如果下载文件与文档库中未回收的原文副本 SHA-256 相同，直接打开已有文档，保留其名称、笔记和译文。没有可下载全文或下载失败时，可使用错误提示下方的“在浏览器查看来源页面”，或结果中的“原文页面”。

Sci-Hub 的默认地址为 `https://sci-hub.ru`。点击“设置地址”可填写其他 HTTPS 站点地址；更改保存在本机，点击“恢复默认”回到默认地址。地址、站点页面结构或收录情况变化可能导致获取失败。

遇到网站验证时，点击“在 App 中验证并继续”，在临时网页窗口自行完成站点要求。窗口使用系统 WebKit 正常加载网页，应用不自动点击或解答验证码。页面加载完成后会检查全文链接，也可点击“继续打开全文”再次检查；找到 PDF 后交回应用下载和阅读。关闭窗口会停止加载，临时网页数据不与 Safari 共享，也不导出登录凭据。若 PDF 本身仍需要登录状态，匿名下载可能失败，此时使用浏览器来源页面处理。

“取消搜索”“取消下载”会停止对应任务；关闭检索窗口也会停止未完成的任务。下载上限为单文件 100 MB，网页、登录页、验证码和无效 PDF 不会作为文档导入。

搜索与加载更多会把搜索词发送至 OpenAlex；选择 Sci-Hub 打开全文时，DOI 发送至已配置的 Sci-Hub 站点，再从页面提供的 PDF 地址下载。选择公开 PDF 时直接连接文献提供方。不会发送本机 PDF、批注、模型配置或翻译密钥。匿名基础查询受 OpenAlex 的额度及频率限制，遇到限流提示请稍后重试。

## 阅读工作区

顶部紧凑工具栏集中显示文档名称、原文／对照／译文切换、缩放、搜索、翻译和导出。长文件名按可用空间截断，窄窗口减少次要信息，保留主要操作；批注工具位于下一行。

点击工具栏右侧的“阅读笔记”或“助手”打开右栏，并通过右栏顶部标签切换。右栏从阅读区顶部铺到底部，工具位于顶部，内容在中间滚动，输入或导出操作固定在底部。点击右上角关闭按钮可收起右栏，为文档留出更多横向空间。

## 整理文档库

侧栏提供“全部文档”“未分类”“收藏”“最近”和“回收站”。“最近”显示最近 30 天打开或导入的文档；搜索框按文档名称筛选当前范围，排序菜单可按名称、导入时间或最近打开时间排序。

点击 `+` 可新建文件夹。右键文档可重命名、收藏、移到文件夹或移入回收站；正在翻译或取消任务的文档暂不能重命名或回收。在文件夹中导入 PDF 会归入当前文件夹。文件夹也可重命名；删除文件夹会将其中的文档归回“未分类”。

回收站中的文档可通过右键“恢复文档”取回，保留收藏及仍存在的原文件夹归属。回收站不永久删除 PDF，也不会释放其原文或译文占用的磁盘空间。文档重命名改变文档库显示名称，不修改最初导入的外部文件。

旧文档第一次打开时默认属于“未分类”。如果分类数据读取失败，界面会提示并提供重新读取；不要用空文件覆盖 `library.json`，以免失去分类信息。

## 配置翻译服务

进入侧栏底部的翻译服务设置，添加服务，然后：

1. 选择厂商：DeepSeek、阿里云百炼（北京）、硅基流动（中国站）、OpenAI、Ollama 或自定义。
2. 在线服务粘贴厂商提供的 API Key；常用厂商不需要手填 URL。
3. 选择模型并保存。可使用预设，或点击“获取模型”读取账户可用列表；需要时可手填模型 ID。

Ollama 不需要 API Key，启动本机服务后点击“获取模型”，选择已下载的模型。自定义服务仍可填写 Base URL；账号所在地域与预设不同、私有网关或其他兼容服务请选择“自定义 API”。

“高级设置”包含配置名称、超时、并发及本机服务地址；自定义 API 的地址直接显示在厂商选择下方。切换厂商或地址会清空当前草稿密钥，防止把旧密钥发给另一个服务。Key 保存在 macOS 钥匙串，配置文件不含 Key。获取模型只请求模型目录；测试连接只发送固定短句，均不会发送文档内容。

## 翻译与对照

选中文档后点击“翻译”或“重新翻译”，选择目标语言和页码范围。任务中显示实际阶段与进度，可取消。失败或取消不会替换上次成功结果。

翻译完成后选择“对照”，左侧原文、右侧译文；可开启同步滚动，通过底部页码跳转，或搜索、选择与复制文字。顶部双击可按 macOS 窗口设置放大/还原。指定页翻译仍保留整份文档，其余页面保留原文。

## 页面导航与批注

页面导航面板包含“页面”“目录”“书签”：点击缩略图跳转；目录来自 PDF 自带的大纲，没有目录的文件会显示空状态，不会自动猜测章节。个人页书签可在阅读工具栏或批注面板中添加、取消。

在 PDF 中选择文字后，可添加高亮或下划线；笔记可关联选中文字，也可添加到当前页。“批注与笔记”中可查看、编辑、删除批注并跳回对应页面。原文和译文分别保存，添加前确认当前选中的来源。

点击 PDF 上的黄色便笺图标打开笔记编辑器；高亮或下划线区域右键选择“编辑批注笔记…”，或点击侧栏对应的铅笔。高亮区域仍可拖选文字。编辑窗口上方显示摘录，下方编辑笔记：Return 换行，⌘ Return 保存，Esc 取消；取消不会改动原笔记。长笔记可滚动。

批注不会直接改写已保存的原文和译文。批注数据绑定当前 PDF 的哈希；重新翻译产生新文件时，旧译文批注仍属于旧版本，不会自动迁移到新排版。

## 使用文档助手

文档助手使用“翻译服务”中已经保存的配置和钥匙串密钥，无需重复填写 API Key。在助手面板的“助手模型”中选择配置，可以与翻译使用不同的模型；切换助手模型不会更改翻译服务的选择。本机会记住该选择，重新打开应用后继续使用。

若所选配置已被删除，助手优先使用当前翻译服务，没有可用的当前翻译服务时使用首个已保存配置。没有任何配置时，先到设置的“翻译服务”中添加服务。

选择提问范围、输入问题，再点击“发送”；也可以点击“文档概述”等快捷问题，它们会立即按当前范围和所选模型发送。仅打开面板、切换模型、预览范围或选择文字不会发出模型请求。

| 范围 | 本次提供的内容 |
|---|---|
| 文档问答 | 本机检查原文后选择相关片段，最多 6 页、合计 12,000 个字符；考虑当前页、问题匹配内容及可识别的概述、目的、摘要、结论、要求、步骤和注意事项等章节 |
| 当前页 | 当前原文页的有限片段，最多 2,400 个字符，不一定包含整页 |
| 选中文字 | 当前实际选区，最多 6,000 个字符；选区可能来自原文或译文 |
| 自由提问 | 不新提取 PDF，发送问题与近期对话；近期对话可能含之前讨论过的文档内容 |

每次还会附带最多最近 10 条、合计 8,000 个字符的对话。文档检索本身最多检查 500 页、240,000 个字符；这些是上限，不表示全文已发送或模型已通读全文。界面会显示实际选取的页码与限长提示。

回答中的有效 `[P3]` 一类引用可展开查看当次提供的片段，并跳回对应页面。引用只证明该页片段被提供过，不能证明结论正确；没有提供过的页码会标记为无法核对，不提供跳转。扫描图像、文本层缺失的公式以及未入选内容可能无法回答，请对照原 PDF。

可复制回答或“保存到阅读笔记”，也可取消请求、清空当前文档的对话。对话在本机按文档保存，最多保留最近 40 条并受总长度限制；清空对话不会删除 PDF 或已另存的阅读笔记。使用在线服务时，问题、选取片段和近期对话会发给所选服务；使用本机 Ollama 时由本机模型处理。

## 导出

“导出 PDF”提供原文、译文和双语文件。译文页数与输入一致；双语按“原文第 1 页、译文第 1 页、原文第 2 页、译文第 2 页……”交替排列。系统保存窗口可指定名称和位置。

“批注与笔记”中的“导出批注 PDF”另存当前原文或译文的高亮、下划线与笔记；“导出笔记”生成带页码、摘录和 PDF 哈希的 Markdown 文件。个人页书签会列入笔记导出，不会因此变成 PDF 内置目录。普通“导出 PDF”仍复制已提交的 PDF；需要阅读批注时请选择批注导出。所有导出均应另存到文稿、桌面等目录，不能覆盖 PageBridge 管理的原文、译文或元数据。

## 常见问题

**检查更新失败或找不到新版本：** 确认能访问 GitHub，翻译结束后重试。“自动检查更新”只控制定期检查，不代表自动安装。当前已是最新 build 时不会提示升级；签名或下载失败时不要替换应用内的公钥或关闭验证，使用官方发布页核对版本。

**文献搜索没有结果或无法下载：** 可换用准确标题或 DOI，确认网络后重试。OpenAlex 的检索结果不保证 Sci-Hub 已收录；开放获取记录也不一定提供直接 PDF。可切换全文来源，或检查“设置地址”中的 HTTPS 地址。遇到网站验证时可使用“在 App 中验证并继续”；站点不可用、页面结构变化或其他错误，也可使用“在浏览器查看来源页面”或“原文页面”。检索限流与翻译 API Key 无关，无需修改模型配置。

**连不上模型：** 本机先确认 Ollama 正在运行且模型已下载。在线服务检查厂商/地域、模型权限和 Key；不要把完整 `/chat/completions` 路径填到 Base URL 中。

**文档无法翻译：** 需要可提取文本的 PDF。纯扫描图像暂不提供通用 OCR，加密文件需先解密。首次使用可能需要下载上游字体和版面分析资源。

**显示完整性检查失败：** 可能是模型改写公式、删除数字或产生标签，也可能是源 PDF 的特殊编码或分段导致校验误判。应用会重试，仍失败则不提交本次译文。提示会区分有无旧译文；取得有效诊断时还会显示通过和未通过的段数。可以换模型或按少量页重试，不应把被拒绝的文件当作成功译文。

失败诊断保存在该文档原始副本旁的 `diagnostics/<任务 UUID>.json`，只含计数、固定原因类别和段落哈希，不保存原文、模型回答、提示词或 API Key。被拒绝的 PDF 和临时文件仍会清理。诊断保留用于排错，检查通过也不能代替重要文字和公式的人工核对。

**获取模型后仍无法调用：** 列表来自服务接口，模型是否允许 Chat Completions、是否有额度和权限仍由服务账户决定。可使用“测试连接”检查所选模型。预设地址不会在保存时发起自动请求。

**为什么还有英文：** 人名、机构、协议/模型名、单位、变量和部分原始图像文字会保留。普通正文中的漏译属于质量问题；遇到时请同时保留原文、页码、模型名和对应结果，便于复现。不要提供 API Key。

**助手没有回答全文问题：** 每次只提供有限片段。可改用当前页、选择关键段落或缩小问题范围；不要将带页码的回答当作整份文档已经核验。AI 回答和机器翻译都可能出现归属、因果、术语或数值关系错误。
