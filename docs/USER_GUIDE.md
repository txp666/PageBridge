# 使用 PageBridge

本指南适用于 Mac 与 Windows 应用。下载地址和电脑配置见 [README](../README.md#下载)；Windows 特有的操作与差异见 [Windows 说明](WINDOWS.md)。

## 安装、更新与卸载

**Mac：** 解压 ZIP，将 `PageBridge.app` 放入“应用程序”。手动更新时先退出旧版，再替换应用。

**Windows 安装器：** 按当前用户安装，无需管理员权限，默认目录为 `%LOCALAPPDATA%\Programs\PageBridge`，也可选择其他可写目录。默认创建开始菜单快捷方式，桌面快捷方式可选；结束页可选择启动应用。手动更新时先退出应用，再运行新版安装器。从系统“已安装的应用”卸载，只移除程序和快捷方式，保留文档、译文、批注、配置和 Windows 凭据。

**Windows 便携版：** 将 ZIP 完整解压到可写目录并保留所有子目录，运行 `PageBridge.Windows.exe`；不能只复制 EXE。更新时将新版解压到新目录，不要混合新旧文件。

替换或卸载程序都不会删除用户数据。Windows 安装版与便携版共用 `%LOCALAPPDATA%\PageBridge`，不要同时运行两者操作同一份数据。Mac 与 Windows 的文档库格式不同，不要互相拷贝数据目录；目前没有跨平台同步。

### Mac 应用内更新

在菜单栏选择 **PageBridge → 检查更新…**。**自动检查更新**只决定是否定期检查，首次会征求同意，可随时在同一菜单关闭。

发现新版后，Sparkle 窗口显示版本和更新说明，由你选择下载、安装或跳过；不会静默下载或安装。更新来自本项目 GitHub Releases，经 HTTPS 获取并校验签名。翻译进行时不能检查更新；若已同意安装后又开始翻译，安装和重启会等翻译结束。

### Windows 应用内更新

从左上角 `+` 菜单或“翻译服务”设置左下角选择 **检查更新…**。只在你打开此入口时检查，不会后台定期检查或自动下载。

1. 发现新版后显示版本、安装包大小和更新说明；点击“下载更新”才开始下载，可随时取消。
2. 下载完成后点击“安装并退出…”。翻译、助手回答或保存操作仍在进行时不能安装；未保存的服务设置和助手草稿会先请你确认，阅读位置会先保存。
3. 应用校验更新清单签名和安装包 SHA-256，然后退出并打开安装向导。

便携版也能检查更新，但下载的是安装器：它会安装到已有安装位置或默认目录，**不会替换便携文件夹**。想继续用便携版，请从 Releases 下载新版 ZIP。

两端更新检查都不发送 PDF、笔记、模型配置或 API Key。更新签名用于确认更新来自本项目，不能代替 Apple 公证或 Windows Authenticode，系统安全提示仍可能出现。

## 开始阅读

点击左上角 `+` 或按 `⌘O`（Windows `Ctrl+O`）导入 PDF；Mac 也可以拖入文件。导入会在应用数据目录建立独立副本，不修改原文件。

点击“示例 PDF”可导入随应用附带的五份公开文献（4 页短文到 19 页公式论文），打开示例不会自动翻译。作者和许可见[示例说明](../demos/README.md)。

顶部工具栏包含文档名称、原文／对照／译文切换、缩放、搜索、翻译和导出，批注工具在下一行。点击“阅读笔记”或“助手”打开右栏，右上角按钮收起。

## 整理文档库

侧栏提供“全部文档”“未分类”“收藏”“最近”和“回收站”。“最近”显示 30 天内打开或导入的文档；搜索框按名称筛选当前范围，排序菜单可按名称、导入时间或最近打开时间排序。

点击 `+` 新建文件夹。右键文档可重命名、收藏、移到文件夹或移入回收站；正在翻译的文档暂不能重命名或回收。在文件夹中导入的 PDF 归入该文件夹；删除文件夹会把其中的文档移回“未分类”。

回收站中的文档可右键“恢复文档”。回收站不永久删除 PDF，也不释放磁盘空间。重命名只改变文档库中的名称，不改动最初导入的外部文件。若分类数据读取失败，界面会提示并提供重新读取；不要用空文件覆盖库索引。

## 搜索在线文献

点击侧栏的“搜索在线文献”，或从 `+` 菜单进入。OpenAlex 负责检索，Sci-Hub 和公开 PDF 是可选的全文来源；不需要翻译服务或 API Key。

1. 输入标题、关键词、DOI（例如 `10.1371/journal.pcbi.1003833`）或 `https://doi.org/…` 链接，点击“搜索”或按回车。已知 DOI 时，选择 Sci-Hub 来源后可直接点击空结果区的“直接打开此 DOI 的全文”，不必等待 OpenAlex。
2. 每页最多 20 条结果，可“加载更多”；勾选“仅开放获取”后重新搜索。修改搜索词或筛选条件会清空旧结果。
3. 在“全文来源”中选择 **Sci-Hub**（默认，按 DOI 查找）或 **公开 PDF**（使用 OpenAlex 的开放获取地址），点击结果中的“打开全文”。没有 DOI 的记录只能尝试公开 PDF。
4. 应用下载并校验文件后导入文档库并打开，不会自动翻译。与文档库中已有文件相同（SHA-256 一致）时，直接打开已有文档，保留其名称、文件夹、笔记和译文。
5. 没有可下载全文或下载失败时，使用“在浏览器查看来源页面”或结果中的“原文页面”。

Sci-Hub 默认地址为 `https://sci-hub.ru`，可通过“设置地址”（Windows 为“地址与检索配置”）改为其他 HTTPS 地址，“恢复默认”可还原。

遇到网站验证时，点击“在 App 中验证并继续”，在临时网页窗口自行完成站点要求；应用不会自动点击或解答验证码。找到 PDF 后自动交回应用下载。浏览器 Cookie 和登录状态不会交给下载器，必须登录才能下载的 PDF 可能仍需在浏览器中处理。

单个文件上限 100 MB；网页、登录页、验证码页和无效 PDF 不会被导入。关闭检索窗口会停止未完成的搜索和下载。搜索词发送给 OpenAlex，DOI 发送给所选 Sci-Hub 站点，公开 PDF 直接从文献提供方下载；不会发送本机 PDF、批注、模型配置或 API Key。匿名查询受 OpenAlex 频率限制，遇到限流请稍后重试。

## 配置翻译服务

进入侧栏底部的翻译服务设置，添加服务：

1. 选择厂商：DeepSeek、阿里云百炼（北京）、硅基流动（中国站）、OpenAI、Ollama 或自定义。
2. 在线服务粘贴 API Key；预设厂商不需要填写地址。
3. 选择模型并保存。可使用预设、点击“获取模型”读取账户可用列表，或手填模型 ID。

Ollama 不需要 API Key：启动本机 Ollama 后点击“获取模型”，选择已下载的模型。其他地域、私有网关或兼容服务选择“自定义”，填写 Base URL（不要包含 `/chat/completions`）。

“高级设置”包含配置名称、超时、并发和本机服务地址。切换厂商或地址会清空草稿中的 Key，避免把旧 Key 发给另一个服务。Key 保存在 macOS 钥匙串或 Windows 凭据管理器，不写入普通配置文件。“获取模型”只请求模型目录，“测试连接”只发送一句固定短句，都不发送文档内容。

## 翻译

选中文档后点击“翻译”，选择目标语言和页码范围，生成原页版式阅读稿并保存在文档库中。任务中显示实际阶段和进度，可以取消。取消或失败不会替换上次成功的阅读稿。

阅读稿以完整原页为背景，在原段落区域内显示译文，保持页数、分栏和图表位置。文字按区域大小适配，原文是小字时译文最多缩到原字号的 85%；仍放不下的段落右下角显示蓝色“+”（Windows 为橙色标记），点击查看完整译文和原文。照片、色块、水印和细线保留原页背景；原生文字表格保留数字和格线，在原位置翻译文字标签，扫描表格点击查看辅助译文。图片、公式和代码保持原样，行内公式随正文排列；混色标题保留原图，点击查看译文。没有可靠位置的内容从页面旁的入口查看。

对照视图中左右页顶部和缩放比例一致，可双向连续同步滚动，也可关闭同步分别滚动。

**首次使用：** 应用会下载本地识别组件 MinerU 4.0.12 Basic，**请预留约 4 GB 磁盘空间**（电脑配置见 [README](../README.md#电脑配置)）。先安装独立的 Python 运行环境和依赖，再下载 818 MB 模型，界面显示“正在下载 MinerU 模型：x / 818 MB”。模型优先从 ModelScope 下载；失败或 2 分钟内没有收到任何数据时，自动改从 Hugging Face 下载。组件保存在 `~/Library/Application Support/PageBridge/mineru/4.0.12`（Windows 为 `%LOCALAPPDATA%\PageBridge\mineru\4.0.12`），不在应用程序目录内，替换或卸载程序不会删除它。之后解析在本机离线完成；翻译仍使用你配置的 Ollama 或 API。

**失败与重新生成：** 某段翻译失败时，该段显示原文和未译标记，修正服务配置后可单独重试，其余段落不受影响。整页解析失败时需要重新生成阅读稿。**重新生成会用这次选择的页范围替换当前阅读稿，不会追加到旧稿**；想保留原来的范围，请重新选择完整的页码。

原 PDF 始终不变；扫描识别不会给原文件添加文字层。没有阿拉伯文文字层的阿拉伯语扫描页不受识别组件支持，会保留原页并显示原因。

## 页面导航与批注

页面导航面板包含“页面”“目录”“书签”：点击缩略图跳页；目录来自 PDF 自带的大纲，没有大纲时显示空状态；个人书签可在阅读工具栏或批注面板中添加或取消。

搜索在原文和对照视图中查找原 PDF 的文字，在译文视图中查找阅读稿译文。

批注只加在原 PDF 上（原文视图或对照视图左侧）。选择文字后可添加高亮或下划线；笔记可关联选中文字，也可添加到当前页。“批注与笔记”面板中可查看、编辑、删除批注并跳回对应页面。

点击 PDF 上的便笺图标或侧栏的编辑按钮打开笔记编辑器；也可以在批注上右键，选择“编辑批注笔记…”（Windows 为“编辑笔记…”）或“删除批注”，Windows 双击批注区域同样可以编辑。

添加、删除批注和修改笔记都可以撤销：Mac 用 `⌘Z` 撤销、`⇧⌘Z` 重做（也在“编辑”菜单中），Windows 用 `Ctrl+Z` 撤销、`Ctrl+Y` 重做。切换文档后不再撤销上一份文档的操作。Return 换行，点击保存提交，Esc 取消；Mac 另支持 `⌘Return` 保存。

批注绑定原 PDF 的哈希，重新翻译不影响批注。导入文件原有的批注会保留，但笔记面板只管理在 PageBridge 中新建的批注。

## 文档助手

助手使用“翻译服务”中已保存的配置和凭据。在助手面板底部的“助手模型”中可选择与翻译不同的模型，不会改变翻译服务的选择。若所选配置被删除，助手改用当前翻译服务，再没有时使用第一个已保存配置。

选择提问范围、输入问题后点击“发送”，或从底部“快捷提问”菜单选择问题（立即按当前范围发送）。仅打开面板、切换模型或选择文字不会发出请求。

| 范围 | 本次提供给模型的内容 |
|---|---|
| 文档问答 | 本机检索原文后选出的相关片段，最多 6 页、共 12,000 字符；优先当前页、与问题匹配的内容，以及概述、目的、摘要、结论、要求、步骤、注意事项等章节 |
| 当前页 | 最多 2,400 字符，不一定包含整页 |
| 选中文字 | 当前选区，最多 6,000 字符；可能来自原文或译文 |
| 自由提问 | 不提取 PDF，只发送问题与近期对话（其中可能已有文档内容） |

每次另附最近最多 10 条、共 8,000 字符的对话。文档检索本身最多检查 500 页、240,000 字符；这些是上限，模型并未通读全文。

回答中的 `[P3]` 一类引用可展开查看当次提供的片段并跳回对应页；没有提供过的页码会标为无法核对。引用只说明该页片段被提供过，不证明结论正确。扫描图像、缺少文字层的公式和未选中的内容可能无法回答。

可复制回答、“保存到阅读笔记”、取消请求或清空对话。对话按文档保存在本机，最多保留最近 40 条；清空对话不会删除 PDF 或已保存的笔记。使用在线服务时，问题、片段和近期对话会发送给所选服务；使用 Ollama 时由本机模型处理。

## 导出

“导出 PDF”菜单提供原文 PDF、译文 PDF 和双语 PDF；后两者由阅读稿生成，文档有阅读稿时可用；也可按 `⇧⌘E`（Windows `Ctrl+Shift+E`）导出译文 PDF。先选择保存位置，再显示导出进度，可以取消。

- **译文 PDF：** 页数和页序与原文相同，未翻译的页保持原样。
- **双语 PDF：** 每个已翻译的页之后紧跟它的译文页，其余页只有原文。
- 译文以可选择、可搜索的文字写在原段落位置，放不下时缩小字号，不截断；照片、线条、表格格线、公式和未译段落保留原页内容。

导出不需要翻译服务，也不联网。“批注与笔记”中的“导出批注 PDF”另存原 PDF 及其高亮、下划线和笔记；“导出笔记”生成带页码、摘录和 PDF 哈希的 Markdown，个人书签也会列入。普通“导出 PDF”不含 PageBridge 批注。导出请保存到应用数据目录以外的位置。

## 常见问题

**识别组件下载很慢或失败：** 确认能访问 GitHub、PyPI，以及 ModelScope 或 Hugging Face。使用代理时检查代理是否允许这些下载；模型下载停滞 2 分钟会自动换到 Hugging Face。两个来源都失败时会提示检查网络或代理，修正后重新开始翻译即可继续准备。最近一次准备过程的详细输出保存在组件目录的 `setup.log`，反馈问题时可附上。

**检查更新失败：** 确认能访问 GitHub 后重试；Mac 请在翻译结束后再检查。Windows 上若本机代理转发 GitHub 下载出错，可为 `github.com`、`objects.githubusercontent.com` 和 `release-assets.githubusercontent.com` 设置直连。签名或下载校验失败时保留当前版本，不要修改应用内的公钥或关闭验证；可以从发布页手动下载。

**文献搜索没有结果或无法下载：** 改用准确标题或 DOI 后重试。OpenAlex 有记录不代表 Sci-Hub 已收录，开放获取记录也不一定提供 PDF。可切换全文来源、检查 Sci-Hub 地址，或使用“在浏览器查看来源页面”。检索限流与翻译 API Key 无关。

**连不上模型：** 确认 Ollama 正在运行且模型已下载。在线服务检查厂商与地域、模型权限和 Key；Base URL 不要包含 `/chat/completions`。“获取模型”成功不代表该模型可用于对话或账户有额度，可用“测试连接”检查。

**文档无法翻译：** 加密文件需先解密。

**为什么还有英文：** 人名、机构、协议或模型名、单位、变量以及图片中的文字会保留原文。普通正文漏译属于质量问题；反馈时请附原文页码、模型名和结果，不要附 API Key。

**助手没有回答全文问题：** 每次只提供有限片段。可改用当前页、选择关键段落或缩小问题范围；AI 回答和机器翻译都可能在术语、数值或因果关系上出错。
