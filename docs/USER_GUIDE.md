# 使用 PageBridge

本指南描述 0.1.4 的操作流程。该版本的最终打包与验证状态见 [验证记录](VERIFICATION.md)；旧版应用可能没有厂商选择和示例入口。

## 开始阅读

打开 `PageBridge.app`，拖入 PDF 或点击左上角 `+`。左侧文档库保留导入记录。也可以点击侧栏“示例 PDF”，选择五份公开论文之一；应用会建立独立副本，不修改内置示例。

示例从 4 页短文到 19 页公式论文，原始作者和许可见示例窗口的“原文与许可”。打开示例不会自动翻译。

## 配置翻译服务

进入左下角“翻译服务”，添加服务，然后：

1. 选择厂商：DeepSeek、阿里云百炼（北京）、硅基流动（中国站）、OpenAI、Ollama 或自定义。
2. 选择模型。预设可直接使用，也可以填入 Key 后点击“获取模型”读取账户可用列表；需要时可手填模型 ID。
3. 在线服务粘贴厂商提供的 API Key，点击保存。常用厂商不需要手填 URL。

Ollama 不需要 API Key，启动本机服务后点击“获取模型”，选择已下载的模型。自定义服务仍可填写 Base URL；账号所在地域与预设不同、私有网关或其他兼容服务请选择“自定义 API”。

“高级设置”包含配置名称、地址、超时与并发。切换厂商或地址会清空当前草稿密钥，防止把旧密钥发给另一个服务。Key 保存在 macOS 钥匙串，配置文件不含 Key。获取模型只请求模型目录；测试连接只发送固定短句，均不会发送文档内容。

## 翻译与对照

选中文档后点击“翻译”或“重新翻译”，选择目标语言和页码范围。任务中显示实际阶段与进度，可取消。失败或取消不会替换上次成功结果。

翻译完成后选择“对照”，左侧原文、右侧译文；可开启同步滚动，通过底部页码跳转，或搜索、选择与复制文字。顶部双击可按 macOS 窗口设置放大/还原。指定页翻译仍保留整份文档，其余页面保留原文。

## 导出

“导出 PDF”提供原文、译文和双语文件。译文页数与输入一致；双语按“原文第 1 页、译文第 1 页、原文第 2 页、译文第 2 页……”交替排列。系统保存窗口可指定名称和位置。

## 常见问题

**连不上模型：** 本机先确认 Ollama 正在运行且模型已下载。在线服务检查厂商/地域、模型权限和 Key；不要把完整 `/chat/completions` 路径填到 Base URL 中。

**文档无法翻译：** 需要可提取文本的 PDF。纯扫描图像暂不提供通用 OCR，加密文件需先解密。首次使用可能需要下载上游字体和版面分析资源。

**显示完整性检查失败：** 某些模型会改写公式、删除数字或产生标签。应用会重试，仍失败就保留旧结果并报告错误；可以换模型或按少量页重试，不应把被拒绝的文件当作成功译文。

**获取模型后仍无法调用：** 列表来自服务接口，模型是否允许 Chat Completions、是否有额度和权限仍由服务账户决定。可使用“测试连接”检查所选模型。预设地址不会在保存时发起自动请求。

**为什么还有英文：** 人名、机构、协议/模型名、单位、变量和部分原始图像文字会保留。普通正文中的漏译属于质量问题；遇到时请同时保留原文、页码、模型名和对应结果，便于复现。不要提供 API Key。
