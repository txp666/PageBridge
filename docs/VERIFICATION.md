## 通过条件

1. **任务完整：** 退出成功，输出可读，单语 N 页、双语 2N 页，原始 PDF 未改变；没有未解决段落或占位符残留。
2. **内容保真：** 核对普通正文漏译、重要数字、公式对象与脚标。人名、元数据、技术名称、原图文字和有证据保留的源结构单独识别，不能直接按拉丁字符数量判断漏译。
3. **版面可读：** 逐页查看低分辨率渲染，并复核重点页的高分辨率结果；检查遮挡、越界、重叠、参考文献分条、步骤编号、图注与悬挂缩进。
4. **链接正确：** 区分源文件的有效热点与零面积注释，核对恢复后的可见文本位置、URI 或跳转页码；重复年份/编号、脚标、旋转页和双语页映射须有回归覆盖。
5. **交付一致：** 成功结果来自最终代码，包内模块哈希与已验证源码一致；实际原生界面可导入、读取、对照和导出，导出哈希与已提交结果一致。
