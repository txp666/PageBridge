# 界面截图

这些截图由 PageBridge 0.3.0 / build 12 的实际原生窗口生成，展示对照阅读、文献搜索和文档助手。侧栏个人文件列表和服务密钥未出现在截图中；助手展示空对话界面，没有为截图发送在线模型请求。

阅读示例为 Nicolas P. Rougier、Michael Droettboom 和 Philip E. Bourne 的 *Ten Simple Rules for Better Figures*，PLOS Computational Biology (2014)，DOI：[10.1371/journal.pcbi.1003833](https://doi.org/10.1371/journal.pcbi.1003833)。原文按 Creative Commons Attribution 许可发布，见[完整示例归属与来源](../../demos/README.md)。右侧中文为机器翻译示例，不是原作者提供的译本。

搜索结果来自 OpenAlex；全文来源设置与服务状态可能随时间变化。截图用于展示实际产品操作，不构成全文可用性或翻译质量保证。
