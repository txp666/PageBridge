# 界面截图

本目录现有 `reader.jpg`、`assistant.jpg`、`literature-search.jpg` 均由 **Mac PageBridge 0.4.0 / build 13** 的实际原生窗口生成，展示对照阅读、文档助手和文献搜索。截图时收起了文档库侧栏，文献搜索图只截取搜索面板，个人文件列表和服务密钥未出现在截图中。助手展示空对话界面，可见已配置的模型名称和提问范围，没有为截图发送在线模型请求。

阅读示例为 Nicolas P. Rougier、Michael Droettboom 和 Philip E. Bourne 的 *Ten Simple Rules for Better Figures*，PLOS Computational Biology (2014)，DOI：[10.1371/journal.pcbi.1003833](https://doi.org/10.1371/journal.pcbi.1003833)。原文按 Creative Commons Attribution 许可发布，见[完整示例归属与来源](../../demos/README.md)。右侧中文为机器翻译示例，不是原作者提供的译本。

搜索结果来自 OpenAlex（2026-10-26 检索）；全文来源设置与服务状态可能随时间变化。截图用于展示实际产品操作，不构成全文可用性或翻译质量保证。

这些是 Mac 界面，不是 Windows 界面；Windows 功能与已知差异见 [Windows 说明](../WINDOWS.md)。截图未包含模型回答，也未使用含 QA 合成对话的验证截图。
